# Exploratory V2: separating catalytic turnover and reporter abundance

Predict two numerical endpoints for human G6PD missense substitutions. The activity target is untreated purified recombinant enzyme kcat divided by the WT kcat in the same study. This directly measures catalytic turnover. The separate abundance target is the normalized human-cell reporter score from MaveDB 00001266-b-1. Because assay systems and constructs differ, the labels describe paired observations; they do not establish the cellular cause of lost activity.

Use the fixed historical G6PD direct-biochemistry inventory (Gomez-Manzo 2015, Boonyuen 2017 and 2021, Wang 2008 if eligible). Include WT-normalized, finite untreated kcat for every single substitution; retain inactive-without-value as missing. Take the median per substitution when multiple papers cover it. Each training residue gets equal total weight. Build one fixed ridge (alpha 10; intercept unpenalized; weighted centering and scaling) on SaProt structure-aware compatibility, ESMC sequence likelihood and ThermoMPNN predicted stability change. Train a common-signal control on the same activity data using only the existing protein-held-out abundance score. Clamp negative predicted turnover to zero. Fit a linear conversion of the frozen ASPA-trained abundance head's percentile to native G6PD reporter units on all substitutions at the turnover training residues. Use an identical abundance score for the two heads, enabling a matched test of the extra activity inputs. The clinical model remains frozen. Inference consumes only the specified molecular model outputs.

Lock portable heads and scores for all qualified G6PD substitutions before reading or joining paired evaluation measurements. Exclude every substitution at any training residue from evaluation. External biochemical evaluation panels are fixed: PMC7215812, PMC10835850, PMC11641639, PMC12429737. Include all source-qualified single substitutions, direct matched untreated kcat and a WT anchor; exclude compounds, missing or mismatched molecular profiles and training residues with explicit accounting. Take median WT-normalized activity across reports per substitution. Report all four phenotype categories, conditional correct counts among observed low-activity variants for preserved versus low abundance (count any incorrect activity prediction as a miss), per-endpoint continuous error, and baseline on identical cases. Operational cutoffs: low turnover <0.50 times WT; low abundance <0.75 normalized reporter units. These are research definitions, not clinical cutoffs. Only describe minority category performance if represented. No retuning or clinical deployment.

This is retrospective development. Some public activity values were visible in source discovery and earlier publications were investigated; the new score-to-outcome pairing remains unopened when the model is frozen. Holdout is by entire residue in both readout fits. Existing abundance head excluded all G6PD from supervised training. No genuinely prospective, protein-held-out or clinical generalization claim. Public release contains newly written code, fitted parameters, per-substitution derived predictions and aggregate results; raw publisher tables and local absolute paths are omitted.
